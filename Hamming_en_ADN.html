Hamming en ADN

Un texto se convierte en una hebra de A, C, G y T, se le agrega redundancia, se daña con mutaciones al azar y se recupera.

El código

Cada base es un símbolo del cuerpo GF(4), así que el alfabeto tiene q = 4. Un bloque tiene 3 bases de mensaje y 2 de paridad.

Bases como símbolos de GF(4)

A = 0 C = 1 G = ω T = ω2 = ω + 1

Matriz de control H

11110 1ωω201

Al recibir y se calcula el síndrome s = H·yT. Si s = 0, no se detecta error. Si no, s = e · (columna j de H): hay un error de tamaño e en la posición j, y se corrige sumando e.

Demostración

Escribe un mensaje y mueve la probabilidad de que cada base cambie. Se compara con guardar el mismo texto sin código.
